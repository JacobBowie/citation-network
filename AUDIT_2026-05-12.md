## Known issues / accepted tradeoffs

- **Filter changes rebuild the iframe** — vis-network restarts physics on every UI control change (~1-2s stutter, view position lost). Acceptable for slider-style use; full fix requires anywidget bidirectional channel. **Decision: ship as-is for v0.1.**
- **Random seed for x-position** — `Math.random() - 0.5` in init gives a different layout per page load. Replace with `Math.seedrandom` for screenshot-consistent layouts. **Decision: ship as-is for v0.1.**
- **Search is accent-blind** — "Perez" doesn't match "Pérez". Cosmetic. **Decision: ship as-is.**
